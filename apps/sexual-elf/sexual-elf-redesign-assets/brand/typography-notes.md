# Sexual Elf typography notes

## Primary type direction
Use a humanist sans-serif with rounded terminals and good readability.

Recommended web-safe direction:
- Inter
- Manrope
- IBM Plex Sans
- Nunito Sans (only for softer marketing contexts)

## Suggested pairing
- UI / body: Inter 400, 500, 600
- Headings: Manrope 600, 700
- Mono / evidence or technical references: IBM Plex Mono 400

## Tone
- Calm
- Clear
- Non-judgmental
- Evidence-led
- Not cute
- Not sterile hospital UI
